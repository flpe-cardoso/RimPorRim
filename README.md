# Rim Por Rim

Plataforma web educativa sobre **Doença Renal Crônica (DRC)**, desenvolvida como projeto acadêmico de conclusão de curso.

O projeto tem como objetivo disponibilizar informações de forma acessível e interativa para crianças, responsáveis e profissionais.

## Funcionalidades

* Sistema de cadastro e login
* Perfis de usuários
* Conteúdos educativos sobre DRC
* Sistema de progresso por etapas
* Jogos educativos com sistema de pontuação
* Receitas adaptadas para crianças
* Fórum para interação entre usuários
* Área específica para profissionais

## Tecnologias

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* XAMPP

## Projeto

Desenvolvido como Trabalho de Conclusão de Curso no curso técnico de **Desenvolvimento de Sistemas**.

O projeto integra desenvolvimento web, banco de dados e educação em saúde.
